# Smart Complaint Management System

A modern **role-based complaint management web application** that allows citizens to submit and track complaints while enabling staff and administrators to manage, assign, and monitor complaint resolution efficiently.

## 🚀 Features

* 👤 Role-based access for **Citizens, Staff & Admins**
* 📝 Complaint submission with category, priority, location, description, and attachments
* 🔍 Real-time complaint status tracking
* 📊 Interactive admin dashboards and charts
* 👨‍💼 Complaint and staff management
* 🔐 Protected routes and authentication
* 🔔 Toast notifications and form validation
* 📱 Responsive and user-friendly interface

## 🛠️ Tech Stack

* **React.js**
* **JavaScript**
* **Tailwind CSS**
* **React Router**
* **Recharts**
* **Lucide React**
* **Vite**
* **Axios**
* **Express.js**

## ⚙️ Installation

```bash
git clone <your-repository-url>
cd <project-folder>
npm install
npm run dev
```

Open the application at:

```text
http://localhost:5173
```

## 👥 User Roles

| Role    | Capabilities                                               |
| ------- | ---------------------------------------------------------- |
| Citizen | Submit and track complaints                                |
| Staff   | View and manage assigned complaints                        |
| Admin   | Manage complaints, staff, categories and system statistics |

## 📌 Project Purpose

The system aims to **digitize and simplify complaint management**, improve transparency, reduce manual processes, and provide an efficient way to monitor complaint resolution.
